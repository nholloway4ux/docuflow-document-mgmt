Instructions for WordPress Integration

To embed a PDF in your WordPress site:

  1. First, upload a PDF through the admin panel at https://pdfadminwordpress.vercel.app/admin
  2. Copy the PDF ID from the admin panel
  3. In WordPress, add a Custom HTML block or use the Text editor mode
  4. Paste the iframe code below, replacing YOUR_PDF_ID with the actual PDF ID

Option 1: Basic Embed (Full Page)

Use this code in your WordPress page/post:

<iframe 
    src="https://pdfadminwordpress.vercel.app/embed/YOUR_PDF_ID" 
    width="100%" 
    height="800" 
    frameborder="0"
    style="border: 1px solid #ddd; border-radius: 4px;">
</iframe>

Option 2: Responsive Embed

For a responsive embed that adjusts to screen size:

<div style="position: relative; width: 100%; height: 0; padding-bottom: 141.42%;">
    <iframe 
        src="https://pdfadminwordpress.vercel.app/embed/YOUR_PDF_ID" 
        style="position: absolute; top: 0; left: 0; width: 100%; height: 100%; border: 1px solid #ddd;"
        frameborder="0">
    </iframe>
</div>

Troubleshooting

  • PDF not showing: Make sure you've uploaded a PDF through the admin panel first
  • Authentication errors: PDFs are publicly viewable once uploaded, no login required for viewing
  • CORS errors: The embed pages are configured to work in iframes from any domain
  • ID not found: Verify the PDF ID in the admin panel
